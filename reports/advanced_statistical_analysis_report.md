# Advanced Statistical Analysis & Hypothesis Testing

## Dataset

The analysis uses a synthetic business sales dataset containing 180 observations across three regions and two sales channels.

## Methods

The notebook includes:

- Shapiro-Wilk normality test
- Kolmogorov-Smirnov normality test
- Welch two-sample t-test
- Mann-Whitney U test
- One-Way ANOVA
- Tukey HSD post-hoc analysis
- Two-Way ANOVA
- Distribution and box plots
- 95% confidence interval for the primary mean difference

## Significance Level

The analysis uses alpha = 0.05.

## Reproducibility

The dataset, notebook, Python source files, tests, and documentation are maintained in the Git repository.

## Important Limitation

The dataset is synthetic and was created solely to demonstrate an end-to-end statistical analysis workflow. The findings should not be interpreted as evidence about a real-world population.
